# Changelog

Todas as mudanças significativas deste projeto estão documentadas aqui.

## [1.3.0] - 2025-05-27
### Alterado
- `BoardController` refatorada:
  - Renomeação de métodos para maior clareza (`GetBoards`, `SaveBoard`, `UpdateBoard`, `DeleteBoard`).
  - Extração de métodos `HandleException` e `ValidateRequest`.
  - Melhor tratamento de erros com mensagens traduzidas.


## [1.2.0] - 2025-05-27
### Alterado
- `CardController` refatorada:
  - Método `Get` renomeado para `GetCardsByBoard` para melhor clareza semântica.
  - Método `UpdateStatus` renomeado para `UpdateCardStatuses`.
  - Extraído método `HandleException` para centralizar tratamento de erros.
  - Mensagem de sucesso adicionada no endpoint de atualização de status.

### Melhorado
- Redução de duplicação de código com extração de lógica comum.
- Respostas HTTP mais claras e consistentes.


## [1.1.0] - 2025-05-27
### Adicionado
- Novo método privado `HandleException` para centralizar o tratamento de erros.
- Validação com mensagens claras utilizando FluentValidation.

### Alterado
- Nome do método `Save` alterado para `RegisterUser` por clareza semântica.
- Código duplicado nos blocos try/catch foi eliminado.
